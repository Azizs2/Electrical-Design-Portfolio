# 150kV Substation Single Line Diagram (SLD) - GIS System

Designed a high-voltage digital substation architecture for a 150kV Gas Insulated Switchgear (GIS) system in strict compliance with IEC. The layout features a 5-bay configuration (2x Line Bays, 2x Transformer Bays, and 1x Bus Coupler Bay) operating on a dual busbar arrangement (Main 1 & Main 2). Integrated comprehensive CT/VT core schedules mapping knee-point voltage ($V_k$), secondary resistance ($R_{ct}$), burden, and class accuracy for tariff metering, zone bus protection, and backup protection schemes.

**Technologies & Standards Used**: Single Line Diagrams (SLD), GIS Technology, IEC Standards, Protection Interlocking, AutoCAD, Engineering Base.
